Hooke

Image analysis at the speed new models arrive.

An open-source platform for finding, turning on and running the hundreds of models in microscopy and bioimage analysis, with new ones published every week. Run them on your camera, recordings or images, and compare them on the same specimen. No terminal, no broken environments.

HookeUI is developed with AI coding assistants. It is named after Robert Hooke, whose Micrographia (1665) recorded what he saw through his microscope.

How it works

  1. Find a model

    Browse the catalog, paste a BioImage Model Zoo or Hugging Face link, or add a Fiji function or one a colleague shared.

  2. Turn it on

    One action: Download for a model that runs on your Mac, Add key for a cloud model. A model with its own code gets its own environment, checked before use.

  3. Use it on your specimen

    Click, run it from Actions, or ask for it in plain language. Run several on the same view and compare them side by side.

Models, algorithms and capabilities

Hooke’s models, algorithms and Fiji functions come from one shared catalog. An entry can be a segmentation model, a classic algorithm, a Fiji function, a cloud model or a dataset. Anyone can add one, and everyone can run it.

  1. The community adds it

    Each model, algorithm or Fiji function is one catalog entry, added by the people who use it. New entries reach you as catalog updates, without a new app.

  2. You turn it on

    Download for one that runs on your Mac, Add key for a cloud model. Files are pinned and checked; one with its own code gets its own environment. Nothing to set up in a terminal.

  3. You add your own

    Paste a BioImage Model Zoo or Hugging Face link, drop in a Cellpose model you trained, or have an AI assistant draft the adapter, tried in a sandbox before you use it.

  4. You share it back

    Send it as a file anyone can open, or publish it to the reviewed catalog. Results record which entries made them, so others can turn on the same ones.
