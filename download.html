Get started

  1. Use an Apple Silicon Mac. The app targets macOS 14 or later; this candidate’s native verification is on macOS 26.
  2. Open the disk image and drag HookeUI into Applications. Quit another Hooke copy before opening this one. Keep your existing installer and back up your Projects first.
  3. Open HookeUI. First launch prepares its Python runtime and dependencies and needs internet access. It does not require a paid API account.
  4. Choose Open microscope example to begin with the bundled image. Uncalibrated measurements use pixels.
  5. For scientific tools, import a companion package in Models → Add your own → Add model/tool, review its declared requirements, then prepare it.

Updates on your terms

Choose HookeUI → Check for Updates… in the Mac menu bar, or wait for the automatic check. Read the release notes, install when you are ready, or choose Remind Me Later to keep working. Save drafts and finish or stop active work before restarting. Saved Projects stay in your data folder.

Already using the October 19 beta? The same menu now offers version 0.1.1. The app is signed and notarized for direct download; no App Store installation is required.

Scientific companion packages

These optional candidate integrations use Hooke’s public interfaces. They are separately prepared, and their requirements and limits apply. Cellpose model weights are restricted to noncommercial use by their declared license.

  • OME-Zarr reader package — bounded local scientific folder import.
  • Cellpose-SAM 2D package — actual specialist controls, declared model download and retained input/output support.
  • Animation package — camera/dimension keyframes and managed movie export; currently appears as “Private scientific review probe.”

One-page workflow guide

Know what is saved

Use the supported Save controls to retain scientific changes. Closing a control dock does not stop analysis. Private plugin variables and unsaved edits are not promised to survive quitting. Native data export and rendered movie export are separate actions.

Component checks and developer-VM demonstrations support this release. They do not establish complete napari parity, independent contributor qualification, large-data qualification or Windows/Linux support. Comparison and recipe UI replay remain incompletely demonstrated. Recipe steps require explicit execution and review; reopening does not run analysis.

A first native tool opening timed out in the development VM; one in-app retry succeeded. If opening fails, preserve the saved revision and retry once. Do not repeatedly run expensive analysis to recover a display.

Known check failures: two simulated-camera click-latency limits were exceeded. Optional SAM 3.1 outline repair and Molmo pointing failed their local capability check; do not rely on these paths in this release. Full details are in the release files.

Keep the previous installer. Downgrading a newly saved Project format is not qualified; restore a backup made before updating instead.
